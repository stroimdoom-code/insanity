Интерактивный буклет «Что посмотреть в Упорово»

Что уже готово:
- HTML-буклет с перелистыванием разделов
- интерактивная карта
- фотографии и тексты по объектам
- кнопки переходов по разделам
- блоки для трёх видеоподкастов

Видео подключены напрямую через встроенные плееры VK (iframe).
Для загрузки нужен интернет и доступ к VK. Плееры адаптируются к ширине экрана.
Локальные MP4 не используются; папка videos и видеофайлы исключены через .gitignore.

Публикация на GitHub Pages:
1) загрузить index.html, booklet.js, assets, README.txt и .gitignore в репозиторий;
2) открыть Settings → Pages;
3) выбрать Deploy from a branch, ветку main и / (root), нажать Save;
4) открыть опубликованный сайт и проверить три видеоплеера VK.

Навигация:
- Назад и Вперёд переходят на соседние страницы без зацикливания.
- Содержание позволяет открыть любой раздел; кнопка «К карте» возвращает к схеме.
- Адрес #page1 … #page8 позволяет поделиться конкретным разделом.
- Кнопки истории браузера восстанавливают разделы.
- Стрелки клавиатуры листают страницы вне кнопок и окна просмотра фотографий.
- Нажатие на фотографию открывает увеличенный просмотр; Escape закрывает его.
- При уходе со страницы видео сбрасывается, чтобы остановить звук.

Проверка логики навигации: node --test tests/navigation.test.cjs
